# Portfolio Game — 定量リスク分析ツール

日本株30銘柄を対象とした、ポートフォリオゲーム用の定量リスク分析ツール。
yfinanceで株価を取得し、GBM予測・VaR・相関ベースのポートフォリオリスクを可視化する。

## 📊 分析環境（Yahoo Finance / yfinance）

**APIキー・認証情報・課金 すべて不要**。

### セットアップ

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install yfinance pandas numpy matplotlib seaborn scipy ipywidgets jupyter

jupyter notebook analysis/forecast.ipynb
```

### `forecast.ipynb`（★対話UI）
- **1銘柄GBM予測**: 銘柄/推定モード/予測日数を切替、±1〜3σ シグマバンド、VaR 95%/99%
- **3銘柄ポートフォリオ**: 相関行列ベースの真のリスク、分散効果、ポートフォリオVaR
  - **銘柄3は任意銘柄OK**（ティッカー直接入力可、例 `6098.T`）
- 推定モードは `2年平均` がデフォ（過去2年の60日ローリングμ・σの平均）
- 下段に過去2年の **μ・σ水位グラフ** を表示。「今使ってる値」が極端でないか見ながら調整できる

### `risk.ipynb`
1. **直近3ヶ月 × 20日ローリング**（全30 / セクター / 個別の3階層）
2. **2年スパン × 3ヶ月（60日）ローリング**（同じ3階層）

### `volatility_analysis.ipynb`（補助）
- 過去1年の一発スナップショット：年率ボラ棒グラフ／リスク・リターン散布図／30×30相関ヒートマップ／ローリングボラ
